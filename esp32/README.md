# ESP32 구현 버전 안내

보고서의 첫 실행 경로는 [ADXL345·FG V3](../edge_module_c/esp32/edge_alimi_adxl345_fg_report/)다. 3축 512표본과 FG 펄스를 사용하며, 보고서 검증 소스와 독립 PlatformIO 빌드 진입점을 함께 제공한다.

이 폴더의 `edgealimi_v2_realsensor/`는 이전 V2 실센서·벡터 검증 스케치다. `../edge_module_c/esp32/edge_alimi/`는 이전 MPU-6050 V2 HTTP 콘솔 구현이며, 각 계산 조건과 정상 학습 기록은 [이전 V2 안내](../edge_module_c/README.md#이전-v2-계산과-운영-기록)에 연결한다.
