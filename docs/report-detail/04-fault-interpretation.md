# 4. 결함 후보와 물리 신호 해석

**보고서 위치:** Ⅲ-4, 표 8(11쪽)

## 쉬운 설명

결함 유형마다 진동의 반복 주기·방향·충격 구조가 다른 패턴으로 나타나며, 속도·부하·장착 조건도 스펙트럼과 시간 형상에 반영된다. 이 문서는 각 패턴을 회전 차수, 센서 축, 운전 정보와 함께 후보별로 연결한다.

현재 물리 경로는 3축 가속도, FG, 설비 메타데이터에서 계산 가능한 후보를 반환한다. 모델 개발 경로는 불평형·기계적 이완·축 정렬 불량·정상 네 클래스를 출력 후보로 사용한다.

## 회전 차수 주파수 예와 관측 경계

회전 주파수가 $f_r$일 때 회전 차수 $q×$의 중심 주파수는

$$
f_q=qf_r,\qquad f_r=\frac{\mathrm{RPM}}{60}.
$$

정상 팬 조건의 $f_r=68.07\,\mathrm{Hz}$에서 신뢰 상한은 160 Hz다. 대역 반폭 $\max(2\Delta f,0.05qf_r)$를 적용하면 다음 상태가 계산된다.

| 차수 | 중심 | 대역 경계 | 출력 상태 |
|---|---:|---:|---|
| 1× | 68.07 Hz | 64.6665~71.4735 Hz | 가용 |
| 2× | 136.14 Hz | 129.333~142.947 Hz | 가용 |
| 3× | 204.21 Hz | 193.9995~214.4205 Hz | `band_available[FEC_THREE]=false`, `outside_trusted_band` |

이 계산 예의 회전 기준은 PDF 정상 팬 평균 68.07 Hz다. 보고서 검증 사본은 FG 동기 1× 진폭·위상을 계산하고, 최신 확장 경로에는 2×·3× 투영이 포함된다.

| 결함 후보 | 신호 패턴 | 필요한 입력·단위 | 계산 경로와 상태 필드 | 수치·출력의 범위 |
|---|---|---|---|---|
| **회전체 불평형** | 회전 1×의 상대 우세, 기준 대비 진폭 변화, FG 기준 위상 집중 | $f_r$, $R_{1×}$[%], 진폭[g], 위상[rad] | V3의 1× 투영과 최근 5개 위상으로 rho 계산; 물리 후보는 1× 이탈·비중·coherence 입력 사용 | 1× 패턴은 불평형 후보 근거로 출력되고 구조·설치별 원인 정보와 함께 해석 |

| **벨트 느슨함** | 전달 주기·벨트 장력·모터와 구동부 속도비 패턴 | 벨트·풀리 정보, 모터·축 속도, 진동 센서 | AI-Hub 결과는 V2 재생 경로이며 물리 후보 출력은 belt metadata와 보조 근거를 상태로 받음 | 보고서 표 9·10은 파일별 결과와 4/5·20창 비교를 기록 |

## 위상 집중도와 1× 근거

위상 $\phi_i$[rad]를 5개 유효 분석창에서 모아

$$
\rho=\frac{1}{5}\left|\sum_{i=1}^{5}e^{i\phi_i}\right|,
\qquad0\le\rho\le1
$$

$\rho$는 FG 기준 회전 위상의 집중도를 0~1로 나타낸다. 1× 진폭과 정상 기준 변화량을 함께 후보 근거 계산에 전달한다.

## 입력 가용성과 출력 표현

대역 가용성은 신뢰 주파수 폭, FG·표본 시각의 품질, 반복 이력과 설비 메타데이터를 결합해 필드별로 표현한다.

| 입력 상태 | 출력 필드 | 계산 결과 |
|---|---|---|
| 신뢰 대역과 에너지 빈이 가용 | `band_available[]`=true | 에너지 특징과 기준 대비 이탈 계산 |
| 대역 일부 또는 차수 가용성 미충족 | `band_available[]`=false, 이유 코드 | 상태와 관측 범위를 후보 결과에 포함 |
| 위상 5회·FG 연속·표본 시간축 상태 | 후보 availability와 이유 코드 | 가용 위상 이력에서 rho와 후보 상태 계산 |
| 결합부·방향·베어링 기하·벨트 정보 | `candidate_available[]` | 설비 메타데이터에 따라 후보 경로 표시 |

출력에는 후보 유형·근거 강도·입력 가용 상태가 함께 담기며, 운영 기록에서는 설비 회전·부하·장착 조건과 점검 결과를 해당 후보와 연결한다.
