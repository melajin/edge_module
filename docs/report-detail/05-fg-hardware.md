# 5. FG V3와 하드웨어: 회전 기준을 진동에 맞추기

**보고서 위치:** Ⅲ-5(12~15쪽), 하드웨어 구성·FG 처리·표 7

## 시스템에서 FG가 필요한 이유

FG(Frequency Generator) 펄스는 팬 회전 주기마다 기준 시각을 제공한다. 펄스 간격으로 회전 주파수를 구하고, 각 가속도 표본의 회전 위상을 보간해 1× 성분의 진폭과 위상을 동기 계산한다.

이 절은 보고서 검증 빌드 `v3_signal.c`의 계산과 PDF에 기록된 보드 설정·측정값을 연결한다. 펌웨어 입력 구성에는 ADXL345, FG GPIO, PPR 설정, I²C, 시리얼 출력이 포함된다.

## 보고서 검증 사본의 입력 조건

| 항목 | 코드 입력·설정 | 출력 상태·단위 |
|---|---:|---|
| 가속도 표본 개수 | 창당 512 | 축별 분석창 512표본 |
| 가속도 시간 간격 | 표본별 마이크로초 시각 | 창별 실제 표본 시간축 |
| 허용 표본 간격 | 1,800~3,200 µs | 표본 시간축 유효 구간 |
| 계산 샘플링 주파수 | 380~420 Hz | 창 타임스탬프에서 산출한 $f_s$ 범위 |
| 가속도 크기 검사 | $|g|<3.9$ | 입력 범위 상태 코드 산출 |
| FG 입력의 펄스 수 | PPR 1~16 | 회전당 펄스 수 설정 범위 |
| 회전 속도 산출 | FG 주파수 × 60 / PPR | 결과 단위 RPM |
| 표본·시리얼 인터페이스 | I²C 및 115200 baud | 어댑터 입출력 설정 |

표의 표본·FG·통신 값은 V3 구현 설계값이다. 데이터시트 표기와 보고서의 정상 팬 측정값은 각각의 근거 유형으로 구분해 이어 적었다.

## FG 펄스에서 회전수와 위상으로

한 회전에 `PPR`개의 펄스가 있고 연속 펄스 사이 시간이 `Δt`초이면 FG 주파수는 `f_FG=1/Δt` Hz다. 회전 주파수는 `f_r=f_FG/PPR` rev/s, 속도는 `RPM=60f_r`다. 예를 들어 PPR=2, 펄스 간격 21.9 ms이면 `f_FG≈45.7 Hz`, `f_r≈22.85 Hz`, `RPM≈1,371`이다.

FG edge의 누적 순번을 `k`, 회전당 펄스 수를 `PPR`라 두면 펄스 구간 안의 분율 `u∈[0,1)`을 더해 회전 위상을 추정한다.

$$
\theta=\frac{2\pi}{\mathrm{PPR}}(k\bmod\mathrm{PPR}+u).
$$

`u`는 직전 펄스와 다음 펄스 사이에서 표본의 시간 위치를 나타낸다. 구현은 FG 간격 1~100 ms와 창 내 평균 FG 간격 대비 편차 15% 이내를 입력 품질 기준으로 사용하며, 창 사이 연속성은 `reason`의 사유 코드로 기록한다.

## 1× 동기 투영과 부호

한 축의 평균을 뺀 표본을 `x[n]`, 해당 시각의 회전 위상을 `θ[n]`이라 하면 검증 사본은 실수·허수 누적값을

$$
\operatorname{Re}=\sum_{n=0}^{N-1}x[n]\cos\theta[n],\qquad
\operatorname{Im}=-\sum_{n=0}^{N-1}x[n]\sin\theta[n]
$$

로 만든다. 이어서 진폭과 위상을

$$
A_{1\times}=\frac{2}{N}\sqrt{\operatorname{Re}^2+\operatorname{Im}^2},\qquad
\phi_{1\times}=\operatorname{atan2}(\operatorname{Im},\operatorname{Re})
$$

로 계산한다. 진폭 단위는 입력과 같은 g, 위상은 rad다. 허수 누적에 음의 부호를 쓰므로 `atan2`의 부호 관례가 코드와 일치한다. 이 정규화는 동기 투영 진폭이며 빈별 FFT 전력과 단위가 다르다.

보고서 검증 사본은 1× 진폭·위상을 계산한다. `edge_module_c/report_ml/src/v3_signal.c`의 최신 실험 경로는 2×·3× 성분과 에너지 비중을 추가한다.

## 정상 기준과 후보 상태 갱신

보고서가 설명하는 팬 실험에는 축별 1× 진폭 기준값을 만들기 위한 336개 정상 창이 사용됐다. 현재 창의 축별 진폭을 해당 기준값과 비교한다. 0.001 g 기준을 유효 분모 하한으로 두고, 유효 축 가운데 현재/기준 진폭비가 가장 큰 축을 선택한다.

최근 5개 유효 위상의 집중도 `ρ=|Σ exp(iφ)|/5`를 계산한다. 진폭비 기준은 1.1, 위상 집중도 기준은 0.0이다. 처음 5개 위상이 모인 창에서 첫 위상 집중도 결과가 만들어지고, 첫 집중도 결과를 포함한 5개 유효 집중도 결과에 4/5 투표를 적용해 아홉 번째 유효 분석창에서 첫 상태를 출력한다.

V3 결과 JSON은 `reason`, `imbalance`, `imbalance_votes`, `auto_confirm=false` 필드를 기록한다. `reason`에는 `ok`, `fg_gap_reset`, `v3_numeric_input`, `baseline_missing`, `phase_history_warmup`과 센서·신호 사유가 들어간다. 불평형 상태 필드의 값은 `unavailable`, `normal`, `suspected`, `inspection_required` 중 하나다. 대시보드 해석 계층은 원래 `imbalance` 상태를 `imbalance_status` 표시 필드로 보존한다.

## 인터페이스 설정과 기록값

PDF의 어댑터 구현은 ADXL345 주소 `0x53`, I²C 400 kHz, 400 Hz 데이터율, ±4 g full-resolution, 256 LSB/g를 기록한다. 핀 설정은 SDA 21, SCL 22, FG GPIO 25이며 시리얼은 115200 baud다.

| 인터페이스 항목 | 보고서·코드 기록 | 의미 필드 |
|---|---|---|
| ADXL345 | I²C 주소 0x53, 400 Hz, ±4 g, 256 LSB/g | 센서 설정·변환값 |
| FG 입력 | GPIO 25 하강 에지, PPR 1~16 | 입력 에지·회전 기준 |
| FG 시간 품질 | 1~100 ms, 창 내 평균 FG 간격 대비 편차 15% 이내 | FG 유효 상태 |
| 데이터 출력 | JSON의 `reason`, `imbalance`, `imbalance_votes`, `auto_confirm` | 분석 상태와 투표 수 |

이 표는 펌웨어 입력 계약과 PDF에 기록된 센서 설정을 연결한다. 보고서의 정상 팬 행은 운전 중 표본율·FG 주파수·진동 1×와 반복창 통계를 함께 기록한다.

## 보고서에 적힌 정상 운전 결과

보고서 19쪽 표 12는 PPR 설정값 2, 400.52 Hz 표본율, 137.15 Hz FG 주파수, 68.07 Hz 진동 1×를 기록한다. 정상 팬에서 관측한 FG/진동 주파수비는 2.01이다. 336창 중 333창(99.1%)이 3% 이내, 307창(91.4%)이 2% 이내였고 빈 간격은 400.52/512≈0.782 Hz다. 이 행은 정상 팬 운전 관측값이다.
