# 7. 기대효과와 운영 지표

**보고서 위치:** Ⅴ 기대효과(20~21쪽)

보고서는 저비용 진동 센서와 FG 회전 기준으로 설비 상태를 요약하고, 점검자가 후보·근거·운전 이력을 함께 살피는 흐름을 제시한다. 운영 화면에서는 이 흐름을 점검시간, 판정 가능 입력, 후보 확인, 정상 기준 변화로 표현할 수 있다.

## 보고서가 제시하는 기대효과

| 기대효과 | 시스템 기능 | 운영 지표 |
|---|---|---|
| 설비 상태를 반복 점검 | 가속도 표본·FG 기준의 연속 입력 | 장비별 정상 기준과 경향 이력 수 |
| 점검 정보의 현장 접근 | 엣지 계산과 시리얼 상태 출력 | 입력 유효 비율, 상태 표시 지연, 장비별 가용 시간 |
| 후보 근거를 포함한 진단 정보 | 회전 차수·시간 형상·클래스 점수 | 후보별 근거 강도, 상태 전환, 점검 결과 연결률 |
| 점검 운영 효율 | 운전 상태와 점검 결과를 같은 장비 이력으로 관리 | 알림 후 확인시간, 반복 점검시간, 조치 기록률 |

## 현재 기록된 효과·기술 지표

| 증거 유형 | 기록된 결과 | 운영상 읽기 지표 |
|---|---|---|
| 정상 팬 FG·진동 관측 | 336창, 진동 1× 평균 68.07 Hz, FG 137.15 Hz; 333/336창(99.1%) 3% 이내, 307/336창(91.4%) 2% 이내 | 회전 동기 추정 편차와 정상 기준 이력 |
| AI-Hub 파일 재생 | 벨트 4/5 탐지 10,218/16,343; 정상 오경보 538/9,283 | 전체 파일 대비 탐지 비율과 정상 파일 오경보율 |
| CWRU 호스트 재생 | 특징·점수 parity 640창, 세부 클래스 정답 581/640; 4/5 판정 600창 | 구현 간 차이와 분석창 기준 분류 결과 |
| 공개 Mendeley 개발 평가 | 20개 trial-group을 나눈 5개 fold OOF 1,200기록, 정확도 93.67%; 축 정렬 86.00%, 기계적 이완 88.67% 재현율 | 데이터 profile 및 클래스별 재현율 |
| 소프트웨어·타깃 빌드 | Python/C 정책 비교, 합성 C 검사, ESP32 빌드 및 링크 메모리 기록 | 계산 parity, 입력 상태 처리, 빌드 크기 |

정상 팬 측정은 회전 동기 추정의 반복성을 수치로 나타낸다. AI-Hub와 CWRU 표는 공개 파형 재생의 평가 단위를 나타내고, Mendeley 수치는 101특징 모델 개발 fold의 결과를 나타낸다.

## 운영 지표의 정의

| 지표 | 정의 | 단위·분모 |
|---|---|---|
| 판정 가능 비율 | 전체 입력 중 유효 판정이 있는 입력 | %; 전체 파일·창·취득 구간을 경로별로 사용 |
| 조건부 탐지율 | 판정 가능한 고장 입력 중 탐지한 입력 | %; 판정 가능 고장 파일 또는 창 |
| 전체 고장 입력 대비 탐지 비율 | 전체 고장 입력을 분모로 둔 탐지 결과 | %; 전체 분모에 판정 불가 입력 포함 |
| 정상 오경보율 | 판정 가능한 정상 입력에서 이상으로 분류한 입력 | %; 판정 가능 정상 파일 또는 창 |
| 점검 흐름 지표 | 알림 확인시간, 점검 후 상태 갱신시간, 결과 연결률 | 시간, 건수, % |

데이터 단위가 파일, 분석창, 1.6초 취득 구간으로 나뉘므로 평가표는 각 분모를 함께 표시한다. 결과 상태는 normal/suspected/unavailable과 입력 품질 사유를 보존하며, 모델 출력은 후보 label·클래스 마진·가용 차수 상태로 구성된다.
