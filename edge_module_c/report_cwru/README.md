# 보고서 CWRU 베어링 계산

이 묶음은 보고서의 12 kHz·4096점 CWRU 베어링 입력을 여섯 특징과 네 클래스 점수로 분석한다. 특징은 RMS·초과첨도·1×/2×/3×·고주파 비율이며, 대역 비율은 FFT 진폭합으로 계산한다. 정상 클래스 인덱스는 2이며 시간 판정은 4/5 규칙이다.

| 경로 | 역할 |
|---|---|
| [src/](src/), [include/](include/) | C 특징·모델·투표와 어댑터 |
| [python_reference/](python_reference/) | 동결 Python 기준과 소스 해시 |
| [tests/](tests/) | 호스트 인터페이스·유효 입력·수치 비교 |
| [verification/](verification/) | 보고서 기존 평가 기록 |

보고서 기록은 640창의 특징·점수 비교와 정답 581/640(90.78%)이다. 열 개 파일마다 첫 4창을 초기 이력으로 채운 뒤 600창을 평가했으며, 고장 486/486창 탐지와 정상 0/114창 확정 오경보로 집계했다. 입력·분모·재생 조건은 [결과 해설](../../docs/report-detail/06-results.md)에 연결한다.

이 디렉터리의 `python tests/verify.py --basic-only`는 호스트 어댑터의 입력·정책 계약 7개 사례를 검사한다. 동결 MAT 파형 재생은 모델·선정 정보와 원 파형을 입력으로 사용하는 별도 평가 경로다.
