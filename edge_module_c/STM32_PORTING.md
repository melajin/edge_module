# 보고서 계산 모듈의 STM32 이식

이 문서는 보고서의 ADXL345·FG 입력과 C 계산 모듈을 STM32 환경으로 연결할 때 필요한 인터페이스를 정리한다. 기준 실행은 [ESP32 보고서 펌웨어](esp32/edge_alimi_adxl345_fg_report/), 수식과 상태 정의는 [FG 해설](../docs/report-detail/05-fg-hardware.md)에 있다.

## 계산 경로와 입력

| 계산 모듈 | 입력 계약 | 이식 경계 |
|---|---|---|
| 보고서 FG V3 | 3축 가속도 [g], 512표본, 표본 시각 [µs], FG 에지 시각과 PPR | `v3_signal`의 계산 입력, `em_v3`의 정책 상태 |
| 물리 근거 | 512점, 실제 fs·회전 주파수, 설정과 정상 기준 세대 | [report_physical/](report_physical/)의 C API |
| 101특징 | 선택 축 400점·400 Hz, 회전 기준, 생성 모델 계수 | [report_ml/](report_ml/)의 특징·마진 |
| CWRU | 12 kHz·4096점 파형, 여섯 특징과 모델 계수 | [report_cwru/](report_cwru/)의 별도 입력 API |

ADXL345 설정과 FG 구성은 보고서 펌웨어에서 확인하고, 대상 STM32 보드의 전압·핀·인터럽트·타이머 조건은 해당 보드 자료에 맞춰 확정한다. 플랫폼 어댑터는 표본과 시각을 계산 API에 전달하며, 각 API의 반환 상태와 사유를 결과 기록에 보존한다.

## 플랫폼 어댑터

| 영역 | ESP32 보고서 구성 | STM32에서 정할 구현 |
|---|---|---|
| 센서 | ADXL345 `0x53`, 400 Hz·±4 g·256 LSB/g | I²C 드라이버, 표본 상태 확인, 3축 g 변환 |
| 표본 시각 | 마이크로초 시계와 창별 실제 fs | 하드웨어 타이머의 단위·wrap 처리 |
| 회전 기준 | FG GPIO 에지, PPR | 입력 캡처 또는 외부 인터럽트, 에지 이력 |
| 정상 기준 | 축별 기준 진폭과 PPR 저장 | 레코드 크기·버전·저장 방식과 복원 조건 |
| 통신 | 115200 baud JSON 한 줄 | UART 송신과 JSON의 유효값·null 직렬화 |
| 메모리 | 보고서 ESP32 빌드의 RAM·Flash 기록 | 대상 링커 맵, 작업 버퍼, stack 확인 |

512표본의 시각과 FG 간격을 같은 분석창으로 묶고, 입력 오류·분석 중단·시간 단절·기준 변경 때 정책 이력을 새로 시작한다. 모듈별 특징 단위와 정상 기준 계산은 보고서 정의를 유지한다.

## 확인 순서

1. 동일한 합성 입력과 시각을 ESP32 기준 C 및 STM32 호스트 빌드에 전달해 특징과 상태를 비교한다.
2. 센서 취득의 표본 수·실제 fs·시각 간격·누락·클리핑 상태를 기록한다.
3. 정상 운전 조건에서 FG 주파수·PPR·동기 1× 진폭과 위상을 확인한다.
4. 학습·복원·설정 변경에 따른 기준과 이력 상태를 비교한다.

검사 기록에는 보드·컴파일러·입력 출처·설정·예상값·측정값·해석을 남긴다. 보고서의 정상 팬 관측과 기존 ESP32 빌드 수치는 [결과 해설](../docs/report-detail/06-results.md)에 연결한다.
