# 보고서 물리 근거 C 계산

이 묶음은 보고서의 물리 근거 수식에 대응하는 `fault_evidence_core` 소스를 담는다. 3축 512표본과 실제 fs·회전 주파수를 받아 주기형 Hann과 단측 전력을 계산하고, 신뢰 대역 `min(160 Hz, 0.4·fs)` 안의 회전 차수와 시간 형상을 정상 기준과 비교한다.

`fec_extract()`가 특징을 만들고, `fec_baseline_finish()`가 정상 336창의 로그 중앙값·MAD 기준을 생성하며, `fec_evaluate()`가 후보 근거와 가용 상태를 반환한다. 기준의 척도 하한 0.20과 내부 z→d, 후보 결합 수식은 [물리 근거 상세 해설](../../docs/report-detail/02-physical-evidence.md)에 연결한다.

| 경로 | 역할 |
|---|---|
| [include/](include/) | 단위·설정·가용성·결과 C API |
| [src/](src/) | 특징·정상 기준·후보 근거·시간 평활 |
| [tests/](tests/) | C99 계산, C++ 헤더·컴파일 호스트 검사 |

호스트 검사는 이 디렉터리에서 `python tools/run_host_tests.py`로 실행한다. 이번 실행은 C 25개 사례·2,926개 단언과 C++ 헤더·소스 검사를 통과했다. 조건과 실행 결과는 검사 산출물에 기록하며, 정상 팬 관측은 보고서의 장치 기록으로 연결한다.
